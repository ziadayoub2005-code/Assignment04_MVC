الـ Form و الـ Input و الـ Select و الـ Anchor

الـ <form> هو الوعاء اللي بنجمع بيه بيانات اليوزر، وجواه الـ controls زي <input> و <label> و <select>. هنفهم الـ attributes اللي بتضبط كل واحد فيهم، وكلاسات Bootstrap اللي بتزوّقهم، وبعدين تاج الـ <a> اللي بينقل اليوزر بين الصفحات.

الـ form بيلم الحقول ويبعتها مرة واحدة

دوس على أي جزء وشوف مكانه في الكود. وبعدها املا الحقول على اليسار واضغط إرسال: هتشوف المتصفح بيبعت إيه بالظبط.

الشكل الافتراضي للمتصفح (من غير CSS)

        

        

      

    

    

      
<input>تاج من غير إغلاقمفيش </input>، لأنه مفيش حاجة جواه. كل شكله وسلوكه بيتحددوا بالـ attributes، وأهمها type.

      
<label>النص اللي بيوصف الحقلالضغط عليه بيدّي الفوكس للحقل المربوط بيه، وقارئ الشاشة بيقرأه لما يوصل للحقل.

      
for = idالربطقيمة for في الـ label لازم تساوي قيمة id في الـ input. و id لازم يبقى فريد في الصفحة.

    

    

      
طريقة تانية للربط: تلف الـ input جوا الـ label: <label>الاسم <input type="text"></label> وساعتها مش محتاج for ولا id. بس الطريقة اللي فوق هي الأشهر مع Bootstrap.

كل كلاس بيعمل إيه بالظبط

    

      
<form>ده تاج، مش كلاسمفيش كلاس اسمه form محتاج تحطه. التاج <form> شغال لوحده، وBootstrap بيزوّق اللي جواه.

      
.form-labelعلى الـ labelبيدّي النص مسافة تحته عشان ميلزقش في الحقل.

      
.form-controlعلى الـ inputبيخلي الحقل ياخد العرض كامل، بحواف مدورة وpadding وإطار، وبيضيء الإطار لما تركّز فيه. بيتحط كمان على textarea.

      
.form-selectعلى الـ selectنفس فكرة form-control بس للـ select، وبيرسم سهم القائمة. متحطش form-control على select.

      
.mb-3على الـ div اللي حوالين الحقلmargin-bottom: مسافة بين كل حقل واللي بعده. mb = margin-bottom و 3 = حجم المسافة.

      
.btn .btn-primaryعلى الـ buttonكلاسين مع بعض: btn هو الشكل الأساسي للزرار، و btn-primary هو اللون الأزرق.

    

    

      
الكلاس مجرد اسم: form-control مبيعملش حاجة لوحده. هو اسم مربوط بقاعدة CSS جوا ملف Bootstrap، فلازم الملف يكون مربوط بالصفحة بـ <link>. جرّب تطفي أول زرار فوق.

attributes الـ anchor

    

      
hrefالوجهةمن غيره التاج مبيبقاش لينك قابل للضغط. القيمة ممكن تكون URL أو مسار أو #id أو mailto: أو tel:.

      
targetيفتح فين_self (الافتراضي) نفس التاب، و _blank تاب جديد.

      
rel="noopener"أمانبيتحط مع _blank عشان الصفحة الجديدة متقدرش تتحكم في صفحتك.

      
downloadنزّل بدل ما تفتحبيخلي المتصفح ينزّل الملف، وممكن تديله اسم الملف المطلوب.

    

    

      
a ولا button؟ الـ <a> للتنقل: بياخدك مكان تاني. الـ <button> للأكشن: بيعمل حاجة زي إرسال فورم. وتقدر تدّي الـ a شكل زرار بكلاسات Bootstrap: <a class="btn btn-primary" href="...">.
